## Немного о себе

Продуктовый Frontend / Fullstack-разработчик из Смоленска. Работаю с React, TypeScript и Node.js, делаю кроссплатформенные приложения: Web, Electron, iOS и Android на Capacitor.
 
* С сентября 2025 — Frontend-разработчик корпоративного мессенджера и рабочего пространства **LenzaOS**: 650+ закрытых задач, от дизайн-системы и кастомных тем до WebRTC-звонков, Web Workers и realtime-синхронизации по WebSocket. Написал 700+ файлов автотестов.
* Основатель собственного SaaS-проекта **[Abax](https://github.com/MotoIlyuha/Abax)** — интерактивной онлайн-доски с мультиплеером и EdTech-системой для репетиторов (сейчас готовлю к релизу).
* Практикую Spec-Driven AI-разработку: строю пайплайны с ИИ-агентами через архитектурные спецификации (`AGENTS.md`), кастомные скиллы и строгие гейты качества — strict TypeScript, unit- и E2E-тесты.
* В 2025 году окончил Смоленский государственный университет (физико-математический факультет, «Прикладная информатика»), получил диплом о переподготовке по веб-разработке и военный билет.
## Проекты
* **[Abax](https://github.com/MotoIlyuha/Abax)** — Abax Board и Abax Tutor: ядро доски на чистом TypeScript (Canvas-рендерер, Undo/Redo, синхронизация дельта-патчами через WebSocket) и CRM для репетиторов с серверной проверкой ответов. Покрыто 738 unit/server-тестами и 269 E2E-сценариями на Playwright.
* **LenzaOS** — коммерческий продукт, исходный код закрыт.
